Folder `paper/evidence/deep_research/stress/`. Every number below is printed by a script in this folder (stdout in the `.log` next to it); this file is generated by `report.py` from `parts/*.json`, `m7_results.json`, `sanity_clean.json`. Large arrays are in `cache/` (gitignored). No existing file was modified; nothing was committed.

## Setup

* **Simulator** `stress_sim.py` (own module; `iabr2_sim.py` untouched). Base scenes use the exact draw order of `iabr2_sim.simulate` / v1 `make_standard_bank` (angles from the original sampler, alpha ~ CN(0,1/L) sorted, M3 uniform draws, noise CN(0, 10^(-SNR/10)) per beam measurement). The forward model, in order: steering (ideal ULA, or M2 position errors, or M8 spherical wavefront) -> H -> C_r H C_t^T (M1) -> W = diag(D_r) Wq, F = diag(D_t) Fq (M3 per-antenna gain/phase, M4 quantised phase shifters) -> Y = W^H H F + Z -> Y * exp(j Phi) (M6) -> ADC (M5/M5c). Decoders always assume the ideal model: Hant = W_IDEAL Y F_IDEAL^H.
* **Severities**: M1 coupling rho in {0.05,0.1,0.2,0.3} (C[i,i+-1] = rho e^{j th1}, C[i,i+-2] = rho/2 e^{j th2}, th ~ U(0,2pi) per scene, independent Rx/Tx); M2 element positions n + delta_n, delta_n ~ N(0, sigma^2) half-wavelengths, sigma in {0.02,0.05,0.1,0.2}, both arrays; M3 per-antenna phase U(+-20/30/45 deg), gain U(+-6 dB), phase 30 deg + gain 4 dB (the existing model, outside the CNN training range of 8 deg / 3 dB); M4 phase shifters of b in {4,3,2,1} bits (DFT phase index rounded to the nearest multiple of 2^(4-b), ties up; b=4 is bit-identical to ideal); M5 ADC b in {4,3,2,1} bits, mid-rise on Re/Im, per-scene **peak** AGC (full scale = scene max of |Re|,|Im|; no clipping); M5c the same with full scale = 3 x RMS (the task's suggestion; the beamspace peak/RMS ratio is about 12, so this clips the strongest beams: a clipping test more than a resolution test); M6 per-measurement phase noise sigma in {5,10,20,30} deg; M8 near field (spherical wavefront, 28 GHz, lambda/2 spacing, same range r for every path at both arrays, r in {2,1,0.5} m; Fraunhofer distance of the 16-element array ~ 1.2 m).
* **Banks**: L=3, SNR 0 and 15 dB, 500 scenes each; base seeds 5000 (SNR 0) and 5015 (SNR 15). The clean bank and every impaired bank of the same SNR share the same scenes (angles, gains, noise); impairment draws come from `default_rng([seed, code])` and are reused across severities. So "NOMP degradation" is a paired difference on identical scenes. "dist" = 10 log10(mean|Y_imp - Y_clean|^2 / mean|W^H H F|^2), the impairment power relative to the signal.
* **Methods** (all on the same Y): NOMP greedy (known L) on Hant; NOMP + self-calibration SC=(1,5); IABR-Net heat-seeded = decode(Hc, L, heat, "heat", SC); IABR-v2 dual = decode(Hc, L, heat, "dual", SC); network only = parabolic_heat_decode(heat, L); oracle-seeded = cyclic Newton re-estimation (3 rounds) from the true (u,v) on Hant. Decoder from notebook_src.py slice [527:647] via new_results/common.py; CNN IABRv2(32,10,32) final.pt on CPU.
* **Metrics**: paper-style Pd (|err| <= 1 deg per angle component; scenes with < L detections dropped), strict Pd (they count as misses), RMSE over detected components; 95% CI = paired bootstrap, 2000 resamples (single SNR group per bank), seed 0, same indices for all methods and for the matching clean bank.
